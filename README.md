# Order Aruba

Five delivery restaurants from one kitchen in Aruba — Dushi Wok, Taco Brava, Smash Shack, Nonna's Night In and Oranje Snack. Customers mix dishes from any menu in one order and send it on WhatsApp. Delivery ƒ5, pickup free, every night 10 PM to 2 AM.

**Quick changes**
- Hours, WhatsApp number, delivery areas, delivery fee, which restaurants are open: `shared/site.json`
- A restaurant's dishes, prices (in cents) or "sold out today": `<restaurant>/menu.json`

The chef app is at `ops/kitchen/`. Notes for Claude Code are in `CLAUDE.md`.
