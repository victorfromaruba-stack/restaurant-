# Pidi

A late-night delivery app for Aruba: Dushi Wok, Taco Brava, Smash Shack, Nonna's Night In and Oranje Snack. Each restaurant has its own page; one order can mix them, with one delivery fee. Late night from 10 PM, delivered in 45–60 min.

**Quick changes**
- The app's name, WhatsApp number, delivery areas, fees, food minimum, delivery time, which restaurants are open: `shared/site.json`
- A restaurant's dishes, prices (in cents) or "sold out today": `<restaurant>/menu.json`

Notes for Claude Code are in `CLAUDE.md`.
