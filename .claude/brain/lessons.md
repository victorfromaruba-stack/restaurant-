- 2026-10-10 · pidi.css and the old restaurant layer used the same token names for different things (`--ink` was text in order.css, it is the ink ground in pidi.css; same for `--muted`, `--line`, `--display`). Mixing them gave dark text on the ink. The layer tokens are now `--fg`, `--fg-2`, `--rule`, `--r-font`; a restaurant stylesheet sets its rows' colours there, never `--ink`. And `page.clock.set_fixed_time()` in Playwright plus a `timezone_id` that isn't Aruba is the way to test anything on the Aruba clock (qa/check_api.py).
- 2026-10-10 · Dushi Wok went `soon` (9 Oct) and four QA checks quietly broke: they hard-coded Dushi as open (the mix test, the language tickets) and one block just skipped itself. Tests now pick restaurants that are open from site.json, or fake an all-open site.json with `page.route` where they need a specific one. Write new tests that way: Victor changes `status` from his phone.
- 2026-10-10 · The app is Pidi; the old name may stay in a public file only as the old storage and cache names the one-time migration reads (`LEGACY` in qa/check_site.py and the human-touch check.py). Never build the old name from pieces to get past the check.
- 2026-10-09 · A Postgres lockout that RAISE EXCEPTION after writing the failure count never sticks: the error rolls the count back. Admin, kitchen, and driver PIN checks return the sentence (`{ok:false, error}` or text) so the count commits.
- 2026-10-09 · Pidi v2 shares Victor's live bookkeeping database (`cdkopyphjvfxjqhasrae`). The only paste is `driver/v2/supabase/PIDI_SETUP.sql`, and it may create only `public.pidi_*`. Do not enable extensions, create roles, deploy Edge Functions, or alter anything that is not `pidi_`. The anon key is committed in `driver/v2/config.js`. A service role key and a signing JWK are not used. The older lesson's project `orxpuikpgshcajwripxy` is a different paused project. Do not point Pidi at it.
- 2026-10-09 · The Supabase MCP `execute_sql` hangs (60 s timeout, then the worker restarts) on any SQL whose text contains `drop` or `delete`: it waits for an approval nobody sees. Write setup SQL without them (`create or replace trigger`, create a policy only if missing, expire sessions with an update), send it in chunks, and ask Victor to watch for the approval when a real delete is needed (test rows).
- 2026-10-09 · Supabase grants anon and authenticated EXECUTE on every new function and ALL on every new table by default; `revoke … from public` is not enough. Revoke from anon and authenticated by name, then grant back only what the apps call. driver/v2/supabase/tests/run_local.py now mimics those defaults and fails on a leak.
- 2026-10-09 · In PL/pgSQL a variable named like a column (`client_token`) makes `where o.client_token = client_token` fail at run time ("column reference is ambiguous"); the old local tests never sent one. Prefix variables (`v_client`). Every pidi_ function on Supabase must match the tested file: compare `md5(prosrc)` per function.
- 2026-10-09 · Playwright `text=Sign in` also matches "Driver sign in" in a paragraph and clicks that. Use `button:has-text("Sign in")`.
- 2026-10-09 · On a restaurant page its own menu loads in parallel with site.json, so anything that touches the order inside `loadMenu` ran before `setOrder()` knew which order it was (sold-out dishes and new prices never reached that page's order). Order code waits for `KEY`; boot refreshes every loaded menu after `reload()`. To test with a changed menu.json, use a Playwright context with `service_workers="block"`: `page.route` can't see requests the site's service worker makes.
- 2026-10-09 · Browsers break lines after a hyphen or en dash ("stir-/fry", "dine-/in", "35–/50") and `hyphens:none` doesn't stop it. order-app.js `keep()` wraps such words in `<span class="nw">`; use it for any new name or sentence on screen. Never put that span straight inside a flex box next to loose text (a chip's `inline-flex` span ate the space: "Coca-ColaZero"): wrap the label or use plain `esc()` there.
- 2026-10-09 · The restaurant SVG logos had padding and background plates in their viewBox, so they sat indented from the text under them. They're trimmed to their ink now; a new logo needs the same (measure with getBBox in Chromium, drop the full-size background rect).
- 2026-10-09 · With `.nojekyll`, GitHub Pages serves every file in the repo, dot-folders included: /restaurant-/CLAUDE.md and /.claude/brain/victor.md answer 200 on the live site. Anything in the repo is public twice (GitHub and the site). Write internal notes knowing that until the repo is private.
