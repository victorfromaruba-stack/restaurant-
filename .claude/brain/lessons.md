- 2026-10-16 · git pull --rebase on a branch that carries merge commits replays them one by one and conflicts (the Pidi go-live push hit it). When origin/main is an ancestor of your branch (git merge-base --is-ancestor origin/main HEAD), just push; otherwise git pull --no-rebase.
- 2026-10-16 · Playwright: a route handler with two parameters is called as (route, request), so a 'lambda r, c=x:' default-argument trick silently breaks. Under the security lock, string wait_for_function is refused (it needs eval): use wait_for_url(lambda u: ...) or poll with evaluate. Full-page screenshots put sticky bars mid-page: take viewport shots at the top and the end.
- 2026-10-16 · A form with several fields and no submit button never submits on Enter (HTML implicit submission), so an Enter test proves nothing about a submit guard. Test with form.requestSubmit() and a securitypolicyviolation listener (qa/check_site.py does). With the security lock, a page that calls another host (Pidi's Supabase on pidi-live) must list it in connect-src, and inline onclick/onsubmit/<script> no longer run.
- 2026-10-16 · The Write tool turns \uXXXX escapes in its content into the real characters. For regexes that must keep readable escapes (invisible marks in ops/kitchen/kitchen.js), write the file with a script instead.
- 2026-10-16 · Local Postgres for the Pidi SQL tests: not under /tmp/claude-0 (the harness resets it to owner-only), and it must be UTF8 (the SQL has '·' and curly quotes). Use `pg_createcluster 16 <name> -p 5499 -d /var/lib/postgresql/<dir> -e UTF8 --locale C.UTF-8 -- -A trust`, run with `PGPORT=5499 PGUSER=postgres`, then `pg_dropcluster` (`runuser` is refused in a worktree session).

- 2026-10-09 · The Supabase MCP `execute_sql` hangs (60 s timeout, then the worker restarts) on any SQL whose text contains `drop` or `delete`: it waits for an approval nobody sees. - 2026-10-09 · Supabase grants anon and authenticated EXECUTE on every new function and ALL on every new table by default; `revoke … from public` is not enough. - 2026-10-09 · In PL/pgSQL a variable named like a column (`client_token`) makes `where o.client_token = client_token` fail at run time ("column reference is ambiguous"); the old local tests never sent one. - 2026-10-09 · Playwright `text=Sign in` also matches "Driver sign in" in a paragraph and clicks that. Use `button:has-text("Sign in")`.
- 2026-10-09 · On a restaurant page its own menu loads in parallel with site.json, so anything that touches the order inside `loadMenu` ran before `setOrder()` knew which order it was (sold-out dishes and new prices never reached that page's order). To test with a changed menu.json, use a Playwright context with `service_workers="block"`: `page.route` can't see requests the site's service worker makes.
- 2026-10-09 · Browsers break lines after a hyphen or en dash ("stir-/fry", "dine-/in", "35–/50") and `hyphens:none` doesn't stop it. order-app.js `keep()` wraps such words in `<span class="nw">`; use it for any new name or sentence on screen. Never put that span straight inside a flex box next to loose text (a chip's `inline-flex` span ate the space: "Coca-ColaZero"): wrap the label or use plain `esc()` there.
